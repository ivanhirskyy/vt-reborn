# homebrew-vt-puncher

Homebrew tap for [vt-reborn](https://github.com/ivanhirskyy/vt-reborn) — native macOS app for VisualTime.

## Install

```bash
brew tap ivanhirskyy/vt-puncher
brew install vt-puncher
```

## Update

```bash
brew upgrade vt-puncher
```

## Uninstall

```bash
brew uninstall vt-puncher
brew untap ivanhirskyy/vt-puncher
```
